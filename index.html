⚡ MICRO:BIT PROGRAMMING & GITHUB PAGES GUIDE

Follow these easy steps to program your BBC micro:bit in MakeCode:

  1. Open makecode.microbit.org in your browser.
  2. Add an on button A+B pressed block.
  3. Inside it, add a serial write line "A+B" block from the Serial category.
  4. Do the same for Button B (write "B" to crouch).
  5. Connect micro:bit via USB and click **Download** to flash your micro:bit.
MakeCode JavaScript Code Snippet: 
input.onButtonPressed(Button.AB, function () { 
    serial.writeLine("A+B") 
    basic.showIcon(IconNames.Happy) 
}) 
input.onButtonPressed(Button.A, function () { 
    serial.writeLine("A") 
}) 
input.onButtonPressed(Button.B, function () { 
    serial.writeLine("B") 
})

If you prefer MicroPython on micro:bit, use this code:

MicroPython Code: 
from microbit import *

# Initialize USB serial at 115200 baud
uart.init(baudrate=115200)

while True: 
    if button_a.is_pressed() and button_b.is_pressed(): 
        print("A+B") 
        display.show(Image.ARROW_N) 
        sleep(180) 
        display.clear() 
    elif button_a.is_pressed(): 
        print("A") 
        sleep(120) 
    elif button_b.is_pressed(): 
        print("B") 
        sleep(120) 
    sleep(20)

🚀 HOW TO HOST THIS GAME ON GITHUB PAGES FOR FREE:

  1. Create a new repository on GitHub.com (e.g. mario-microbit-game).
  2. Upload this index.html file to the root of your repository.
  3. In your GitHub Repository, click on **Settings** ➔ **Pages** (on the left menu).
  4. Under **Build and deployment**, set Source to **Deploy from a branch**.
  5. Select **Branch: main** (or master) and folder /(root), then click **Save**.
  6. Wait 1-2 minutes! GitHub will give you a live HTTPS link (e.g. https://yourusername.github.io/mario-microbit-game). Web Serial API requires HTTPS or localhost, which GitHub Pages provides automatically!
